# Real India - image candidates

Freely licensed photographs for the **Real India** layer ([design section 10](twice-born-website-design.md)),
one or more for every pairing in [real-india-pairings.md](real-india-pairings.md).

**These images follow the pairings, and the pairings are still unconfirmed.** If a pairing changes, its
images change with it. Nothing here has been downloaded or published.

**How they were found.** The Wikimedia Commons API, filtered to free licences only (CC0, public domain,
CC BY, CC BY-SA), to photographs at usable resolution, preferring Commons' own *featured*, *quality* and
*valued* assessments. Every file below was then checked against its description to confirm it shows what
the pairing needs - which is how the Navi Mumbai railway station stopped standing in for a Himalayan peak.

## Licence obligations, shortest first

| Licence | What the site must do |
|---|---|
| **CC0 / public domain** | Nothing. Credit anyway, as the Codex already does |
| **CC BY** | Name the photographer, link the licence, say if the image was changed |
| **CC BY-SA** | The same, **and** a crop or edit is an adaptation that must itself be CC BY-SA. Using the photo whole avoids the question |

Of the 35 candidates below, 8 are CC0 and one is CC BY; the other 26 are CC BY-SA. The card format will
want crops, so reach first for the CC0 and CC BY images where the layout has to cut, and keep the CC BY-SA
ones whole where it doesn't.

One non-copyright caution: the Archaeological Survey of India requires permission for *commercial*
photography at protected monuments. It does not affect reusing someone else's freely licensed photo on a
site that sells nothing, but it is worth knowing before any of this is printed or sold.

## Gaps

1. **Nagdwari (pairing 9) has no usable photograph.** One 1600x899 file exists and its uploader is
   credited as "Don't Know", so it cannot be credited honestly. The shrines are deep in Satpura and are
   mostly photographed during the Nag Panchami pilgrimage. Three ways out: use a Satpura forest-and-cliff
   landscape and say so in the caption, drop the image and keep the text, or work through Flickr, where
   CC BY photographs of the yatra exist but need checking one at a time.
2. **Halebidu's lake** - the book's temple appearing to float on a taal - is in no free photograph I
   found. The temple is covered thoroughly; its lakeside setting is not.
3. **The falcon altar** exists only at 1000x352. If that codex entry wants a proper figure, the site's own
   SVG diagram convention would serve it better than a photograph: the syena citi is a brick plan, which
   is the kind of thing that convention is for.
4. **Dronagiri, Nagdwari and the Vaitarna** are the three thin ones. Everything else has at least one
   image that would look right on the page.

## Recording them

An accepted image goes into `places.json` with the fields the Codex already uses for real-world pictures,
`imageAlt` and `imageCredit`, plus the licence and a link back to the Commons page:

```json
{
  "id": "dolmen-field",
  "image": "real-hirebenakal.webp",
  "imageAlt": "Dolmens standing in a field on a rocky hillside at Hire Benakal",
  "imageCredit": "Krishnakulkarni36, CC BY-SA 4.0, via Wikimedia Commons",
  "licenseUrl": "https://creativecommons.org/licenses/by-sa/4.0/",
  "source": "https://commons.wikimedia.org/wiki/File:Overview_of_Hirebenakal_megalithic_site.jpg"
}
```

The files would be fetched into `site-assets/art/` as `real-*.webp` by a pipeline step beside
`prepare_art.py`, so the credit travels with the image instead of being typed twice.
